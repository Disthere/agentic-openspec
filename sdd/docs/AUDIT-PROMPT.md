Скопируйте блок ниже целиком в главную сессию DeepSeek Harness с пресетом `sdd`.
Контекст: аудит 2026-11-12 закрыл все 5 P0 и 2 P1; набор с тех пор перестроен —
всё SDD переехало в `sdd/`. Смысл этого прохода — проверить, что перенос ничего не сломал,
и найти то, что не заметили предыдущие аудиты.

## Что стоит проверить отдельно — по следам этой сессии

Эти места уже один раз ломались; вероятнее всего, сломаются снова при следующей правке.

| Риск | Как проверить |
|---|---|
| Пути в бэктиках и промптах (гейты их не смотрят) | прогнать поиск `openspec/`, `tools/`, `dsh/`, `inputs/` без префикса `sdd/` вне папки `sdd/` |
| Ссылка на файл, которого нет в git (например `sdd/METRICS.md`) | убрать игнорируемые файлы и прогнать гейты — так воспроизводится состояние чистого клона |
| Ссылки шаблонов `000-*` | они целятся в место КОПИРОВАНИЯ, не в своё: проверяются только режимом `-Templates` |
| Массовая замена строк | ломала YAML (подмена букв) и `-replace` с тремя аргументами; проверять файл после замены |
| BOM в `.ps1` | PowerShell 5.1 читает файл без BOM как ANSI и падает на кириллице — проверять первый байт |
