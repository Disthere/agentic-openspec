## Непроверенные условия

| Условие | Почему не проверено | Риск | План проверки |
| - | - | - | - |
| Понятность промптов человеком без пояснений | машинно не проверяется | средний: промпт может требовать доработки | первый реальный прогон развёртывания (Capsul-A) — по отчёту сессии скорректировать формулировки |
| Поведение промпта B1 на реальном чужом репозитории | нет второго проекта под рукой | средний: слияние конфигов может дать конфликт | прогон на первом существующем проекте; правила слияния зафиксированы в самом промпте |
| Формулировки команд в списке `SESSION-START.md` | команды — наши служебные фразы, не команды терминала | низкий | обновляются по ходу сессий |
