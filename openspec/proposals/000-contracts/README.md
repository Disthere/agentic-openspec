# Контракты — <NNN-slug>

> Скопируйте папку `000-contracts/` в предложение и положите сюда контракты изменения.
> Правила: [`../../standards/06-api.md`](../../standards/06-api.md), [`../../standards/08-messaging.md`](../../standards/08-messaging.md).

## Что положить

- `openapi.yaml` — HTTP-контракт (или ссылка/инструкция генерации).
- `*.proto` — gRPC-контракты (внутренние).
- `events/*.md` (или `*.json`) — схемы событий: имя, версия, поля, семантика.

## Обязательные требования

- Указана **версия** и **совместимость** изменения (ломающие — по [конституции](../../constitution.md), раздел 4).
- Описана **семантика ошибок** (`ProblemDetails` / RFC 9457) и коды состояния.
- Для событий: семантика доставки, идемпотентность, порядок, retry/DLQ.

## Шаблон описания события

| Поле | Тип | Обяз. | Описание |
| - | - | - | - |
| messageId | uuid | да | ключ дедупликации (идемпотентность) |
| occurredAt | datetime | да | момент события |
| <field> | <type> | <да/нет> | <описание> |
