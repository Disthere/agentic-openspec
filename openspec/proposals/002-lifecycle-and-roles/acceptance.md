## Непроверенные условия

| Условие | Почему не проверено | Риск | План проверки |
| - | - | - | - |
| `--dump-config` показывает шесть пресетов | профиль не установлен (`dsh\install.ps1` ещё не запускался) | средний: опечатка в YAML проявится только при запуске | запустить `install.ps1` + `--dump-config` первой же командой в DSH |
| Читает ли DSH `AGENTS.md` как инструкции воркспейса | открытый `OQ-1` | низкий: персоны перечисляют файлы явно, поэтому правила доходят и без этого | проверка в UI DSH (задача `сделай OQ-1`) |
| Живой прогон новых ролей (Discovery/Verify/Release) | нет реального продукта и материалов | средний: гейты могут оказаться неисполнимыми | первый прогон на первом реальном проекте; результат — в эту таблицу |

## Принятые отклонения от плана

| # | Отклонение | Обоснование |
| - | - | - |
| 1 | Новые скиллы для ролей не созданы | роли на первом шаге самодостаточны; скилл появляется, когда процедура повторится (осознанное ограничение объёма, [`design.md`](./design.md) §4) |
| 2 | Заголовок `.clinerules` переименован в «Правила агента», содержимое переписано под DSH; имя файла сохранено | DSH `.clinerules` не читает; файл остаётся совместимым зеркалом для других инструментов |
| 3 | Три новые роли описаны в `.agents/*.md`, а не как отдельные workspaces/подкаталоги | соответствует существующей конвенции ролей (`.agents/<role>.md`) и составу `config.yaml` |
| 4 | `docs/SESSION-START.md` обновлён в рамках 002 | файл — точка входа следующей сессии; без обновления он описывал бы среду Cline и три роли |
