# Скилл: implement-feature

Ты выполняешь скилл **implement-feature**. Ты реализуешь **утверждённую** спецификацию — и ничего сверх.

## Предусловия

- Существует `openspec/proposals/<id>/proposal.md` и оно утверждено.
- Присутствует `tasks.md`.

Если чего-то не хватает — остановись: *«Blocked: нет утверждённой спецификации.»*

## Шаги

1. Полностью прочитай `proposal.md` и `tasks.md`; составь мысленную карту нужных слоёв/типов.
2. При необходимости сделай скаффолдинг через dotnet CLI (`dotnet new`, `dotnet sln add`) — по Implementation Plan.
3. Реализуй задачи по порядку; держи изменения цельными и в рамках предложения.
4. Добавляй тесты xUnit рядом с кодом, покрывая сценарии требований.
5. Отмечай `- [x]` в `tasks.md` по каждой выполненной задаче.
6. Прогони гейт верификации и зафиксируй вывод:

   ```powershell
   dotnet restore
   dotnet build --configuration Release --no-restore
   dotnet test  --configuration Release --no-build
   dotnet format --verify-no-changes
   ```

7. Доложи Оркестратору: `DONE`/`BLOCKED`, затронутые файлы, команды + счётчики pass/fail, отклонения.

## Ограничения

- Никаких незапрошенных фич или зависимостей.
- Не редактируй спецификацию; вместо этого эскалируй отклонения.
- Зелёные сборка и тесты обязательны до передачи работы.
