# Скиллы (Skills)

Переиспользуемые параметризованные возможности, которые может загружать субагент. Формат повторяет
референс OpenSpec (`.agents/skills/<name>/SKILL.md`) и конвенции скиллов Claude/Cline.

## Структура

```text
skills/
└── <skill-name>/
    ├── SKILL.md        # обязателен — фронтматтер + инструкции
    ├── references/     # опционально — исходные материалы, на которые ссылается скилл
    └── agents/         # опционально — переопределения под конкретные модели (например, openai.yaml)
```

## Фронтматтер `SKILL.md`

Ключи фронтматтера (`name`, `description`, `argument-hint`) — на английском (это конвенция и их читает
движок скиллов); значения можно писать по-русски.

```markdown
---
name: <kebab-case-name>
description: <что делает + когда применять>
argument-hint: <что передаёт вызывающий>
---
```

## Доступные скиллы

| Скилл | Когда применять |
| - | - |
| [`spec-first`](./spec-first/SKILL.md) | Превратить запрос в черновик спецификации (без кода). |
| [`implement-feature`](./implement-feature/SKILL.md) | Реализовать утверждённое предложение с `dotnet build`/`dotnet test`. |

## Как добавить скилл

1. Создай `.agents/skills/<name>/SKILL.md` с фронтматтером выше.
2. Сделай его действенным: предусловия, нумерованные шаги, ограничения и критерии готовности.
3. Ссылайся на него из соответствующего файла роли в `.agents/`, если он должен загружаться автоматически.
