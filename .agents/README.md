# `.agents/` — роли и скиллы субагентов

Здесь хранятся **роли** и **скиллы**, которые Cline использует в режиме Оркестратора.

## Роли

| Файл | Роль | Отвечает за | Никогда не делает |
| - | - | - | - |
| [`architect.md`](./architect.md) | Архитектор | Требования, диаграммы C4/Mermaid, `openspec/proposals/*` | Не пишет реализационный код |
| [`csharp-dev.md`](./csharp-dev.md) | Разработчик | Реализацию C# + `dotnet build`/`dotnet test` | Не меняет спецификацию в одностороннем порядке |
| [`reviewer.md`](./reviewer.md) | Ревьюер | Вердикт о соответствии спецификации (`Pass` / нарушения) | Не правит код, который проверяет |

## Скиллы

Переиспользуемые параметризованные возможности лежат в [`skills/`](./skills). Каждый скилл — это папка
с файлом `SKILL.md`, который начинается с YAML-фронтматтера (`name`, `description`, `argument-hint`).

- [`skills/spec-first/SKILL.md`](./skills/spec-first/SKILL.md) — превратить запрос в черновик спецификации.
- [`skills/implement-feature/SKILL.md`](./skills/implement-feature/SKILL.md) — реализовать утверждённую спецификацию.

## Протокол делегирования

Cline (Оркестратор) запускает по одному субагенту на каждую сфокусированную цель через инструмент
субагентов Cline CLI (`spawn_agent`), затем объединяет полученные отчёты:

```text
Запрос пользователя
   │
   ▼
Оркестратор (Cline, основной контекст)
   ├─ spawn architect      → openspec/proposals/<NNN-slug>/  ──┐ (ревью человеком + утверждение)
   ├─ spawn csharp-dev     → src/ + tests/  (dotnet build/test) │
   ├─ spawn reviewer       → "Pass" | нарушения ───────────────┘ (цикл до Pass)
   └─ отчёт пользователю
```

Правила:

- Промпт субагента = файл роли **плюс** конкретная задача и путь к нужной спецификации.
- Проси у каждого субагента **краткий отчёт** (затронутые пути, ключевые решения, статус), чтобы
  основной контекст оставался чистым.
- Ревьюер — всегда независимый проход от Разработчика.
