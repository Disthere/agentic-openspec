## Запас (headroom)

- Целевая утилизация под пиком — не более 70% CPU и 80% памяти.
- Ёмкость инстанса х N реплик должна покрывать пик с запасом ≥30%.
- Узкие места (БД, брокер, внешний сервис) лимитируют раньше CPU — проверять отдельно.

## Масштабирование

- Горизонтальное (stateless): `kubectl scale` / HPA по метрикам (RPS, CPU, длина очереди).
- Вертикальное — только после замера (см. [`../../openspec/standards/11-performance.md`](../../openspec/standards/11-performance.md)).
- Правила backpressure при деградации (см. [`../../openspec/standards/02-architecture.md`](../../openspec/standards/02-architecture.md)).
