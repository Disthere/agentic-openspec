## Готовые команды

Напиши одну из фраз — выполняется **ровно она и ничего больше**.

| Команда | Что будет сделано |
| - | - |
| `статус` | Короткая сводка: где мы и что открыто (без правок) |
| `проверь репо` | `git status` / `log` + сверка с `origin/main` |
| `включи CI` | выдать scope `workflow`, перенести workflow в `.github/workflows/`, запушить |
| `установи DSH-профиль` | `dsh\install.ps1` + проверка композиции `--dump-config` |
| `сделай OQ-1` | проверить чтение `AGENTS.md` в DSH, закрыть вопрос в `OPEN_QUESTIONS.md` |
| `начни канбан` | создать репозиторий из шаблона и запустить цикл (Discovery → Архитектор → …) |
| `handoff-каталог` | завести `handoff/.gitkeep` + правило именования |
| `шаг ревьюера: handoff` | добавить Ревьюеру проверку чек-листа вычистки пакета наружу |
| `пуш` | закоммитить и запушить текущие изменения |

Новые команды дописывай в эту таблицу.

1. `docs/SESSION-START.md` — этот файл.
2. `CHANGELOG.md` → раздел `[Unreleased]` — что менялось последним.
