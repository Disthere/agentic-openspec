## Правила (кратко)

1. **Привязка обязательна** — `(<ID>)` в заголовке записи. Без ID запись не принимается.
2. **SemVer**: MAJOR — ломающее, MINOR — новая функция, PATCH — исправление.
3. **Пишутся только непустые секции** — пустые удаляются.
4. Каждый пункт отвечает: **что** (тип/метод/ключ), **где** (файл/слой), **эффект** (зачем/как меняется поведение).
5. **Дефолты и breaking** — явно: секция `Не изменилось` для совместимого дефолта, `Миграция` для ломающих.
6. Changelog обновляется **в том же PR**, что и изменение; входит в DoD релиза.
7. Незавершённое — в `## [Unreleased]`; при релизе переносится в `## [X.Y.Z] — YYYY-MM-DD`.
