# INDEX — реестр документации, существовавшей до внедрения SDD

Реестр документов проекта и карта соответствий «их документ → наш артефакт». Это **вход всех решений
по документации**: документ, которого нет в реестре, для процедуры не существует.
Как пополнять — см. [`README.md`](README.md); нормы — [`04-documentation.md` §4.10](../../openspec/standards/04-documentation.md).

| ID | Документ | Где живёт | Владелец | Потребитель | Актуальность | Наш артефакт | Действие | Статус | Примечание |
| - | - | - | - | - | - | - | - | - | - |
| — | *пока пусто* | — | — | — | — | — | — | — | Добавьте первую строку при появлении документа |

Статусы: `⏳ не разобран` · `🔎 в разборе` · `✅ учтён (<NNN-slug>, D-NNN)` · `🗄 архив (не актуален)` ·
`➡ указатель` · `🌐 внешний` · `❓ вопрос (OQ-N)` · `❌ отклонён (D-NNN)`.

## Правила реестра

1. **ID** — `LEG-NNN`, сквозной и не переиспользуется (как `IN-NNN` и `OQ-N`). Строка не удаляется:
   судьба документа выражается статусом, а удаление — отдельное решение владельца.
2. **`Где живёт`** — путь в репозитории **или** URL. Для внешнего документа обязательны владелец
   и причина в `Примечании`: без них строка не принимается.
3. **`Владелец` / `Потребитель`** — кто отвечает за документ и кто им пользуется (команда, роль,
   внешний адресат). Неизвестное значение — `неизвестно`, а не пустая ячейка.
4. **`Актуальность`** — `актуален` / `устарел` / `исторический` / `противоречит коду` / `неизвестно`.
5. **`Наш артефакт`** — путь нашего артефакта либо явно «нет соответствия».
6. **`Действие`** — одно из: `перенос` · `перенос → указатель` · `выгрузка → <наш артефакт>` ·
   `оставить + маркер` · `указатель` · `внешний указатель` · `вопрос (OQ-N)` · `отклонить (D-NNN)`.
7. **`Статус`** — словарь из [`README.md`](README.md); меняется только при реальном продвижении.
8. **Реестр хранит метаданные, а не правила.** Содержание документа в строку не переносится.

## Пример заполнения

Репозиторный документ и внешняя страница — так выглядит заполненная строка:

| ID | Документ | Где живёт | Владелец | Потребитель | Актуальность | Наш артефакт | Действие | Статус | Примечание |
| - | - | - | - | - | - | - | - | - | - |
| LEG-001 | `docs/api.md` | репозиторий: `docs/api.md` | <команда/человек> | <команда/роль> | актуален | `openspec/specs/orders/spec.md` | перенос → указатель | `⏳ не разобран` | — |
| LEG-002 | «ADR-7: Outbox» | Confluence, URL | <владелец страницы> | <команда/роль> | актуален | `docs/architecture/adr/007-outbox.md` | выгрузка → ADR | `⏳ не разобран` | нет прав на выгрузку → `OQ-N` |
