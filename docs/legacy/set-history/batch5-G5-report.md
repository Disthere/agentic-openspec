## Найденное и исправленное сверх плана

**Дефект вывода артефактов (критичный для раздачи).** `tests/Directory.Build.props` —
ближайший к тестовому проекту — заставлял MSBuild считать корнем `UseArtifactsOutput` каталог
`tests/`, из-за чего тесты выводились в `tests/artifacts/bin/...`, а приложение — в
`artifacts/bin/...`. Документированная команда запуска тестов ломалась бы у каждого, кто взял
шаблон. Исправлено явным `<ArtifactsPath>$(MSBuildThisFileDirectory)../artifacts</ArtifactsPath>`.

**Битые ссылки в шаблонах реестров.** После сброса `CHANGELOG.md`, `OPEN_QUESTIONS.md`,
`DECISIONS.md` на корневые позиции унаследовали ссылку `../openspec/...`, верную только из `docs/`.
Линк-чек это не ловил, потому что работал лишь в режиме `-All`. Исправлено: ссылки поправлены,
`-CheckLinks` стал независимым переключателем, линк-чек добавлен в `check-template-clean.ps1`
и **доказан негативным тестом** (битая ссылка → exit 1).

**Ложные срабатывания проверки реестров.** Шаблоны содержат строки-заполнители (`<...>`,
`YYYY-MM-DD`); проверка считала их «историей набора». Уточнено: реальной записью считается
только строка без угловых placeholder-ов.

**Конфликт архива и чистоты шаблона.** `-Archived` требовал дельты в `openspec/specs/`, а чистота
шаблона требует убрать спеки набора оттуда. Разрешено честно: дельта считается влитой, если она
есть в `specs/` **или** в архивной копии `docs/legacy/set-history/specs/`.
