## Правила

1. **Номер `D-NNN` сквозной и не переиспользуется** — так на него можно ссылаться из кода, CHANGELOG и OQ.
2. **Решение фиксируется в момент принятия**, а не задним числом.
3. **Отмена — новой записью** со ссылкой; старая помечается `⛔ отменено D-XXX` (не удаляется).
4. **ARCH-значимые решения** дублируются в ADR; в обоих документах — перекрёстные ссылки.
5. **Запись появляется при закрытии `OQ-N`** либо при принятии решения по ходу реализации.
6. Порядок — **новые сверху**.
